Half日记 iOS 更新命令

第一步：Pull + Build + Sync

cd ~/heartbox-mobile && git pull && npm run build && npx cap sync ios
已复制!

第二步：修改版本号

sed -i '' 's/1.5.4/1.5.5/g' ios/App/App/Info.plist && grep "CFBundleVersion" -A 1 ios/App/App/Info.plist
已复制!

第三步：Xcode操作

Build号改成比当前大的数字，然后：Product → Archive → Distribute App
